`index.html` 하나로 완결되는 모바일 청첩장 시안입니다. 외부 빌드 도구·라이브러리 없이 브라우저에서 바로 열립니다(폰트만 Google Fonts에서 불러오고, 실패하면 시스템 폰트로 대체됩니다).

- 신랑 **민정원** ♥ 신부 **이하은**
- 예식 **2027. 2. 21(일) 오후 1시 30분**, **더뉴컨벤션 2층 홀** (서울특별시 강서구 공항대로36길 57)
- 화면 폭 430px 기준, 390px 모바일에서 검증
- 예식장·주소·전화·좌표는 실제 값 반영됨. 계좌·혼주 정보는 미확정이라 "예식 전 업데이트 예정" 안내만 표시합니다. AI 영상은 아직 자리표시자입니다.
- 초대 문구에는 두 사람이 만난 연도·월·일을 쓰지 않습니다(계절과 장소 중심). 모의고사는 예식·식 전 인사·당일 이벤트·오시는 길 4문제로, 하객이 청첩장을 보며 기분 좋게 맞힐 수 있는 담백한 문항입니다.

  - 선택: **참석할게요 / 마음만 전할게요(미참석) / 아직 미정이에요** — 참석을 골랐을 때만 `동행 인원(본인 포함 1~5명+)`·`식사(식사 예정/안 함/미정)`가 열립니다.

## 이번 업데이트 — 설원 픽셀 방명록

2월 겨울 예식에 맞춰 픽셀 방명록을 16비트 게임 맵 수준으로 다시 만들었습니다.

- **16비트 설원 예식장 배경**: 아치·페어리라이트·랜턴·버진로드·눈 덮인 상록수가 있는 탑다운 도트 배경(`snow_garden_bg.png`, 780×975). HTML 안에 webp base64로 내장되어 파일 하나만 열어도 그대로 뜹니다.
- **도트 캐릭터 커스터마이징**: 24×32 픽셀 그리드에 1px 진한 아웃라인, 피부·머리 명암, 표정, 바닥 타원 그림자를 넣은 캐릭터를 코드로 생성합니다. 헤어 6종 × 헤어 컬러 5종, 겨울 의상 5종 × 컬러 5종, 표정 4종, 소품 4종을 조합할 수 있고, 시트 상단에 실시간 미리보기가 나옵니다. 고른 캐릭터는 브라우저에 기억됩니다.
- **탑다운 공간감**: 캐릭터가 2프레임 걷기 모션으로 눈밭과 버진로드를 오가고, 진행 방향에 따라 좌우가 뒤집히며, 아래쪽(가까운) 캐릭터일수록 조금 크게 그려집니다. 캐릭터를 누르면 말풍선이 톡 뜨고(다른 캐릭터는 살짝 흐려짐), 빈 눈밭을 누르면 그쪽으로 모여듭니다.
- **설원 연출**: 캔버스 위로 픽셀 눈송이가 은은하게 내리고, 빈 곳을 누르면 작은 눈부스러기가 튑니다.
- 예시 하객 5명도 모두 새 도트 캐릭터(장발·가르마·올림머리·숏컷·비니)로 다시 구성했습니다.

## 실제 값으로 바꾸기

`index.html` 안의 `const CONFIG = { ... }` 한 곳만 고치면 됩니다.

```js
groom / bride        이름
dateISO / dateLabel  예식 일시 (캘린더 추가 링크는 dateISO 기준)
venue / address / addressJibeon / venueTel / venueSite / lat / lng
introVideo           'intro.mp4' 처럼 영상 경로를 넣으면 애니메이션 대신 실제 영상이 재생됩니다
guestbookEndpoint    방명록·교환권을 서버로 보낼 주소 (POST)
quiz[]               문제·보기·정답 index·해설 (4문제 고정 아님, 개수 자유)
accounts             측별 계좌 목록
```

- **AI 커플 영상**: `introVideo`에 mp4/webm 경로를 넣으면 `<video autoplay muted loop playsinline>`로 자동 교체됩니다. 영상이 없을 때는 노을 실루엣 애니메이션이 자리표시자로 나옵니다(음소거 기본, 재생/일시정지 토글 연동).
- **방명록·퀴즈·RSVP 수집**: `CONFIG.supabaseUrl`/`supabaseKey`가 채워져 있으면 `guestbook`·`quiz_submissions`·`rsvp_responses` 테이블에 바로 적재하고, 방문 기록은 `rpc/track_visit` 으로 보냅니다(스키마·권한은 `supabase-rsvp-schema.sql`, 확인용 뷰 `v_visitor_summary`·`v_ref_summary`). 값을 비우면 이 기기의 localStorage만 사용합니다.
- **ref 태그**: 하객에게 나눌 링크 뒤에 `?ref=company` 처럼 붙이면 링크별 UV·참석 현황을 나눠 볼 수 있습니다.
- **설원 배경**: `snow_garden_bg.png`(780×975, 4:5)가 원본이고, `index.html`에는 같은 그림을 192KB webp로 base64 내장했습니다. 그림을 바꾸려면 `#scene > .bg-img`의 `src` 데이터 URI를 교체하면 됩니다.
- **공유 썸네일**: `og:image`가 `preview_hero.png`를 가리킵니다. 배포 시 절대 URL의 1200×630 이미지로 바꿔 주세요.
- **지도**: 주소·전화·좌표는 실제 값입니다(더뉴컨벤션웨딩, 37.5564877/126.8369635). 지도 앱 검색 링크는 예식장명(`더뉴컨벤션웨딩`)으로 걸었고, 티맵 딥링크는 앱 설치 시 동작합니다.
- **계좌**: `accounts.groom`/`accounts.bride`가 비어 있으면 화면에는 "혼주 및 계좌 정보는 예식 전 업데이트 예정입니다." 만 나옵니다. 실제 값(`{bank, number, holder}`)을 넣으면 아코디언·복사 버튼이 그대로 살아납니다.

## 알려진 제한

- 방명록·모의고사·RSVP는 Supabase 공용 DB에 저장되어 모든 기기에서 함께 보입니다(로컬 백업도 유지). DB가 막히면 로컬 저장으로만 동작합니다.
- RSVP의 성함·연락처는 모두 선택이라, 보내지 않으면 그 방문자는 뷰에서 visitor_id만 보입니다.
- 인트로는 실제 영상이 없어 SVG 애니메이션 자리표시자입니다.
- 지도는 실제 지도 API가 아닌 픽셀 일러스트이고, 버튼은 지도 앱 검색 링크입니다.
- 설원 배경은 생성 이미지라 해상도(780×975)를 넘겨 확대하면 픽셀이 뭉개질 수 있습니다.
- 캐릭터 그림은 코드로 그리는 도트라, 같은 설정이면 항상 같은 캐릭터가 나옵니다.
